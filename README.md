# Simulink Model Examples for AURIX™ TC4x
Several Simulink model examples are available for AURIX™ devices in this repository.<br />

**NOTE:** For any question or request, please use the dedicated [Infineon AURIX™ forum](https://community.infineon.com/t5/AURIX/bd-p/AURIX).



## Source code
The source code of each example can be generated ouf of MATLAB Simulink using the Embedded Coder for AURIX™. The Embedded Coder is based on Infineon Low Level Drivers (iLLDs), for which the documentation can be found on the top right of [this webpage](https://www.infineon.com/aurix-expert-training).<br />


### Name
The name of each model example follows a specific naming scheme:

&lt;example category&gt;&#95;&lt;board short name&gt;&#95;&lt;example name&gt;

e.g. : HSP&#95;TC499&#95;Trajectory&#95;Planning&#95;Control

where:

- The **example category** is an identification number for the example category (e.g. HSP stands for Hardware Support Package)
- The **board short name** describes which board the example code has been developed for (using board-specific port pins such as LED, communication, etc.)
- The **example name** summarizes in a couple of words the scope and the model used in the example
